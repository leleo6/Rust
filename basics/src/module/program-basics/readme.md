## Necesario para ejecutar el codigo
**Tener en cuenta** : para poder ejecutar el codigo simpre debe estar referenciado
en el archivo main.rs o en alguno que este vinculado a este.

- **pub** : hace que la funcion sea publica 
- **mod** : 
    - mod.rs : normalmente cuando se hacen nuevas carpetas con codigo
    este es el primer archivo que se crea ya que cuando se va a referenciar codigo 
    si esta dentro de una carpeta el sistema no entiende donde buscarlo amenos que 
    se tenga un documento mod.rs o se especifique la ruta.
    - mod : se usa para organizar codigo
